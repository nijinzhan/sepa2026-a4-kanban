# 长音频 CPU 识别耗时与内存复测

日期：2026-11-21（北京时间）
范围：当前工作区的 A-4 音频解码、WebRTC VAD 与教师版 SenseVoice CPU 推理；不调用 A-3/A-5 服务或数据库。

## 结果

使用 120 秒历史 MP3 单次顺序推理。模型成功加载，VAD 检出 10 段，其中 9 段返回非空识别结果；第 8 段（101.18–102.16 秒，长 980 ms）返回空文本。用户抽听该段确认只有噪声、没有语音，因此它是 VAD 短误检，不是 ASR 漏识别。测量脚本仍按原始输出将其记为一个空结果，故机器摘要状态为 `partial_failure`；其余 9 段未逐段人工复核。

| 阶段/指标 | 实测 |
|---|---:|
| 文件读取 | 0.0002 秒 |
| MP3 解码 | 0.866 秒 |
| 模型初始化 | 1.256 秒 |
| VAD | 0.399 秒 |
| 10 段 ASR 合计 | 7.703 秒 |
| 端到端（读入至最后一段识别） | 10.777 秒 |
| ASR 时间 / 音频时长 | 0.064 倍 |
| 端到端时间 / 音频时长 | 0.090 倍 |
| 峰值工作集（Peak Working Set） | 452.4 MiB |
| 峰值页面文件用量（Peak Pagefile Usage） | 1,906.6 MiB |

耗时包含一次模型初始化；端到端时间还包含音频读取、解码、VAD 和各段 ASR。页面文件用量是 Windows 进程计数器值，和常驻工作集不是同一指标，故分开记录。

## 结论边界

这次结果回答了本机 CPU 上 120 秒音频的模型加载、分段与资源耗时；不代表团队 A-3→A-4→A-5 HTTP/数据库全链路耗时，也没有建立人工逐字参考，因此不能据此计算识别准确率。用户已抽听 `101.18–102.16 秒` 并确认只有噪声；该段应作为一次 VAD 短误检记录，不计作语音漏识别。其余识别文本没有逐句核对。
