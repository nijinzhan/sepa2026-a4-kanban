# 教师 SenseVoice ATC 模型效果评测

日期：2026-10-30；负责人：李洪；范围：RQ-A-4-10、RQ-A-4-20 本地识别引擎质量诊断。

## 1. 结论

教师提供的ATC int8模型在既有固定49条ATCO2录音上，严格词错误率（WER）从通用版的 **82.29% 降至 36.77%**，绝对下降 **45.52个百分点**，相对词错误减少 **55.31%**。按单条录音比较，45条改善、2条变差、2条相同。教师版适合作为当前默认识别引擎，但输出仍需人工复核。

这是复用已观察样本的本地对照诊断，不是VHHH独立验收；不知道这些录音是否与教师训练数据重合。WER不能转换为“100%减WER”的识别准确率，也不能据本次结果宣称目标机场质量已达标。本次没有训练、修改模型、搜索参数或替换默认配置。

## 2. 固定条件与数据核验

- 同一49条公开英语ATCO2录音，7个机场各7条，共327.616秒，严格参考词892个；没有VHHH录音。
- 音频、XML源文件、冻结清单和参考文本均逐项核对SHA-256；通用版49条原始输出与2026-10-23历史结果逐条一致，严格S/D/I也一致。
- 两版均实际运行本机CPU模型，使用同一WebRTC分段，共54段；每条起止时间均与历史冻结分段一致。英语、`useItn=true`、2线程、16 kHz单声道及分段参数相同。
- 教师版名称/版本为`SenseVoiceSmall-ATC-VHHH / teacher-2025_0706-int8`；通用版为`SenseVoiceSmall / 2024-07-17`。实际模型及词表哈希记录于机器可读摘要和执行快照。
- 严格评分复用既有分词及编辑距离实现：统一大小写并去除标注和标点，保留数字写法差异；按全体词数汇总`WER=(S+D+I)/N`，不是逐录音WER的简单平均。
- 所有49条均纳入，没有推理失败或事后剔除；评分函数既有12项测试通过，另用独立编辑距离计算复核两版共98条条件、每条两种评分，结果一致。

| 指标 | 通用版，本轮复跑 | 教师ATC版，本轮实测 |
| --- | ---: | ---: |
| 严格WER，越低越好 | 82.29% | 36.77% |
| 严格S / D / I，参考N=892 | 360 / 366 / 8 | 196 / 107 / 25 |
| 数字格式归一化WER，辅助诊断 | 65.85% | 36.81% |
| 呼号完整保留，辅助诊断 | 1 / 65（1.54%） | 18 / 65（27.69%） |
| 数字串完整保留，辅助诊断 | 47 / 111（42.34%） | 75 / 111（67.57%） |
| 推理失败录音 | 0 / 49 | 0 / 49 |
| 分段数 | 54 | 54 |

数字归一化是项目既有的保守自定义规则，参考词数为902，不是官方ATCO2评分。归一化后仍有明显差距，说明本轮严格WER改善不只来自数字写法变化。呼号和数字串要求对齐后整段连续完整匹配；呼号XML含`correct_tagging=0`，这些值只作为诊断，不能直接叫作呼号/数字业务准确率。

## 4. 仍需处理的问题

教师版仍有196次词替换、107次漏词和25次插入；相较通用版，替换和漏词明显减少，插入从8次增加至25次。呼号整体匹配和数字串匹配仍不充分，不宜直接把机器稿当作复核通过的文本。

对齐诊断发现`fife/five`、`tousand/thousand`等拼写或空管发音转写变体，也存在数字、呼号、台站名及词语遗漏。这些情况需要结合音频区分语义错误与转写规范差异；本轮保留原评分规则，没有看到结果后修改映射来降低WER。3条录音出现带`~`的原始模型输出，已保留在本机原稿中；未以删除符号或替换拼写来改写`textRaw`。

下一步优先为VHHH C15或教师指定测试音频建立经人工听音复核的固定参照，单列呼号、频率、高度、航向等关键内容，再按相同流程评分。现有VHHH C15没有可核验参照，本次不计算其WER，也不将其他模型草稿作为真值。
