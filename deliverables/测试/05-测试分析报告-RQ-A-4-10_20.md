## 1 引言

### 1.1 编写目的

汇总本人两项需求已经形成的测试结果、发现、能力和限制，为阶段检查、后续联调及交付判断提供依据。个人实现、真实模型、历史数据库实验和纯团队主仓库部署分别评价，不以一次pytest通过或非空识别文本代替全系统验收。

### 1.2 背景

被测软件为可视化ATC地空通话语音标注系统中本人负责的两个功能：使用sherpa-onnx/SenseVoice生成通话文本与起止时间，保存并管理生成文本。任务由现代软件工程课程提出，李洪开发个人服务和适配器，供自动编排、界面及查询导出功能调用。

主要开发验证环境是Windows本机，ASR在独立进程中使用教师模型，数据库实验使用本机Docker中的PostgreSQL。课程目标业务后端为Linux/Debian、1 vCPU、512 MB，ASR另配运行资源。本机CPU推理、实验容器和历史合作库不等同于该目标环境或团队常驻服务部署。

当前个人成果提交为团队主仓库 [`7a66eef3969f219dc45f9bfa1a0d7f6ea31f9d17`](https://github.com/kenzed/SEPA2026_TeamBlue/commit/7a66eef3969f219dc45f9bfa1a0d7f6ea31f9d17)。报告以各项证据注明的实际版本为准，不把11/07结果改写成11/10最新团队版本已经联调通过。后续严格使用团队主仓库交付开展联调，不用P-Blue补齐业务结构后冒充团队main部署成功。

### 1.3 定义

| 术语 | 含义 |
| --- | --- |
| ASR | Automatic Speech Recognition，自动语音识别 |
| VAD | Voice Activity Detection，语音活动检测 |
| UTC | Coordinated Universal Time，协调世界时；绝对时间含明确时区 |
| UUID | Universally Unique Identifier，用于录音、片段、任务及文本标识 |
| 模拟边界 | 使用测试替身提供上游响应，验证本方处理逻辑；不证明真实上游服务可用 |
| partial | 识别过程部分成功；不等于所有文本已经持久化 |
| 保存确认 | saveConfirmed=true且读回核对一致；与HTTP状态和识别状态分别判断 |
| 未确认 | 请求或提交结果无法明确判断，应先按标识核对而非盲目重发 |
| CER / WER | 字错误率/词错误率；历史对照使用过，本轮轻量检查不设其通过门槛 |
| MiB / OOM | 二进制内存单位/内存不足终止；512 MiB不等于十进制512 MB |

### 3.2 T02 分段转写、异常及处理上限

要求：时间边界合法，状态和计数一致；失败后停止后续识别且保留有效结果；部署配置`maxSegments`为正整数，默认500，超限在登记/建任务/识别前拒绝。

实际：现有`test_segments`、`test_outcomes`、`test_service`、`test_http_api`及`test_limits`用例覆盖合法/无效输入、无语音、失败/部分成功、幂等、忙状态和上限。11/07修复验证包括非法配置（含布尔值）、N−1/N/N+1、默认500拒绝501段、配置501后允许进入任务创建。超限检查确认零片段登记、零任务及零推理。证据R6及对应[上限测试](../../tests/test_limits_2024141460331.py)。
