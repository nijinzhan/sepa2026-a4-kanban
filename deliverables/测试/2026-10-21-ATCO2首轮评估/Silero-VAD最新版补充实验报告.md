# Silero VAD 最新版补充实验报告

> 2026-10-23 状态更新：本文保留原日期实验事实和指标；当前主方案已恢复为 sherpa-onnx + SenseVoice，XLS-R/WebRTC 仅保留为比较实验。当前选型与复现入口见[选型说明](../../../docs/模型选型与实验结论说明.md)。

日期：2026-10-21

实验性质：探索性补测；复用此前评测过的 ATCO2 样本，不是独立测试，也不代表 VHHH 性能。

## 结论

已在本机使用 `silero-vad==6.2.3` 运行新版 Silero VAD，并将它切出的片段送入与前次相同的 XLS-R 检查点。当前结果没有证明新版 Silero 或 WebRTC 是稳定赢家：v6 的平均 WER 略高于 WebRTC、略低于 v5，但两组按录音配对的 95% bootstrap 区间都跨过 0。边界代理指标上，v6 比 v5 有改善，WebRTC 的语音时长覆盖率和边界中位误差仍更好。

因此，这次结果足以补上“最新版是否值得测”的证据，但不足以据此更换项目默认 VAD。课程项目可以保留 WebRTC 与 Silero v6 两个候选，等新的独立样本和人工边界标注后再定。

## 为什么原对照没有一开始就用最新版

原实验先冻结 Silero v5 和 WebRTC 两个 VAD 条件，目的是固定已有基线、单独比较边界切分对 XLS-R 转写的影响，并保持主实验可复现。这种冻结有利于解释那一轮结果，但不能回答“当前最新 Silero 是否更适合 ATC”的问题。现在补做 v6 是合理的；它单列为探索性结果，不回写或覆盖此前冻结的六组对照。

还需区分软件包版本和模型能力版本：`6.2.3` 是当前安装包的发布版本；它的官方发布说明主要是依赖、导入和音频 I/O 方面的维护，并未宣称识别质量提升。官方关于模型能力的改进说明主要见 v6.0 和 v6.2。

## 实验设置

- 样本：此前已评测的 49 段 ATCO2 英语录音，合计 327.616 秒，来自 LKPR、LKTB、LSGS、LSZB、LSZH、LZIB、YSSY 七个机场；没有 VHHH 录音。
- VAD：Silero 官方包 `silero-vad==6.2.3` 内置 JIT 权重，SHA-256：`e1122837f4154c511485fe0b9c64455f7b929c96fbb8d79fbdb336383ebd3720`。
- 参数：16 kHz；阈值 0.5；最短语音 250 ms；最短静音 500 ms；最大语音段 20 s；padding 0 ms；窗口 512 samples。阈值和主要时长参数沿用原 v5 实验设置，未在这批样本上为 v6 调参；由于 v5 与 v6 使用不同封装，这不保证两者处在完全匹配的实际工作点。
- ASR：同一 XLS-R 300M ATC 检查点，本机 RTX 5060 Laptop GPU、CUDA、FP32、CTC greedy 解码；不使用外部语言模型。所有条件用同一冻结评分器。
- 实现差异：前次 Silero v5 条件经 sherpa-onnx 运行；v6.2.3 使用官方 Python API。故比较的是当前可部署的模型加封装路径，不是只替换权重后的纯模型对照。

## XLS-R 转写结果

| 输入分段 | 严格 WER | 数字归一化 WER | 语音段数 |
|---|---:|---:|---:|
| XML 人工区间（控制组） | 39.80% | 39.47% | 66 |
| Silero v5.0 | 43.05% | 42.24% | 67 |
| WebRTC | 40.81% | 40.35% | 54 |
| Silero 6.2.3 包内模型 | 41.93% | 41.69% | 58 |

差值定义为“v6 减对照”，按录音进行 10,000 次配对 bootstrap：

| 对照 | 指标 | WER 差值 | 配对 95% 区间 | 是否跨 0 |
|---|---|---:|---:|---|
| Silero v5.0 | 严格 WER | -1.12 个百分点 | [-3.53, +1.04] 个百分点 | 是 |
| Silero v5.0 | 数字归一化 WER | -0.55 个百分点 | [-2.93, +1.57] 个百分点 | 是 |
| WebRTC | 严格 WER | +1.12 个百分点 | [-2.58, +4.17] 个百分点 | 是 |
| WebRTC | 数字归一化 WER | +1.33 个百分点 | [-2.30, +4.21] 个百分点 | 是 |

点估计显示 v6 略优于 v5、略差于 WebRTC；区间跨 0，因此样本没有证明这些差别稳定存在。

## VAD 边界代理诊断

这里用 XML 转写时间区间作为语音边界代理，不是逐帧人工标注的 VAD 真值。覆盖率和边界误差只用于诊断，不能等同于正式 VAD 准确率。

| VAD | 语音时长覆盖率（recall） | 语音时长精确率 | 起点绝对误差中位数 | 终点绝对误差中位数 |
|---|---:|---:|---:|---:|
| Silero v5.0 | 89.01% | 97.36% | 318 ms | 142 ms |
| WebRTC | 98.10% | 93.32% | 75 ms | 55 ms |
| Silero 6.2.3 包内模型 | 92.55% | 97.01% | 278 ms | 82 ms |

v6 相比 v5 覆盖更多参考语音区间，起止边界中位误差也下降；WebRTC 的覆盖率最高，起点和终点中位误差最低。v6 的时长精确率接近 v5。

## 下一步

1. 不用当前复用样本调整阈值后再报告“测试集结果”。若要调阈值，先划出独立开发集，再用全新录音做最终评估。
2. 如需严谨比较边界质量，补充少量逐帧或精确起止时间人工标注；XML 语音转写区间不足以作为可靠边界真值。
3. 在同一封装/参数口径下对照 v5、v6 和 WebRTC，并记录 VAD 单独耗时及端到端 XLS-R WER。特别留意 v5/v6 封装差异可能影响对照解释。
4. 当前主结论写为“新版已完成探索性补测，暂未发现显著优于 WebRTC 的证据”；不要将官方通用域错误率改善直接写成 ATC 场景提升。
