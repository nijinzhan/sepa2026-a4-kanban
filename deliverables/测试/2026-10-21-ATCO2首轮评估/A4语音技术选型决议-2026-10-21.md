# A-4 语音技术选型决议

决议日期：2026-10-21

状态：历史决议；自2026-10-23起已由[恢复原方案的选型说明](../../../docs/模型选型与实验结论说明.md)替代。下文保留2026-10-21当时的选择与验证记录，不再作为当前默认配置或验收安排。

## 确定采用

| 职责 | 本版本确定采用 | 固定配置 |
|---|---|---|
| 语音活动检测与分段 | WebRTC VAD `webrtcvad-wheels==2.0.14.post1` | aggressiveness=2；16 kHz 单声道；20 ms 帧；静音间隔合并 500 ms；丢弃短于 250 ms 的语音段；padding=0 ms |
| 英语 ATC 语音识别 | `Jzuluaga/wav2vec2-xls-r-300m-en-atc-uwb-atcc-and-atcosim` | revision `01a4853599abf22090b8963e6167b08a890b1e90`；权重 SHA-256 `8967523e4d6f79daa431dbc4a36374a2c3e67697f70e5860e4614f23fea498b8`；16 kHz 单声道；FP32；CTC greedy；不加外部语言模型；本地推理 |

实施配置采用上述固定版本。升级模型、权重或 VAD 参数时，应建立新版本记录并完整回归，不在同一版本内静默替换权重。

## 决策依据

1. 冻结的 49 段 ATCO2 英语录音上，XLS-R 在 XML 控制、Silero v5 和 WebRTC 三种输入下的严格 WER 分别为 39.80%、43.05%、40.81%；SenseVoiceSmall 对应为 79.15%、82.29%、82.29%。相同样本、参考文本、评分器和分段输入下，XLS-R 明显优于当前 SenseVoiceSmall 基线。
2. WhisperATC 联合微调模型虽然在作者 113 段验证集加入元数据后得到 16.96% 严格 WER，但该验证集用于作者模型选择，而且现有 49 段中 38 段和其公开训练划分重合。运行时提示还依赖项目当前无法保证取得的航路点、候选呼号等额外元数据，因此不作为本版本实现。
3. VAD 方面，WebRTC 与 Silero v6 的 WER 差异在 49 段上的配对区间跨过 0，不能宣称统计显著胜出；但 WebRTC 点估计 WER 为 40.81%（v6 为 41.93%），语音时长覆盖率 98.10%（v6 为 92.55%），起止边界误差中位数 75/55 ms（v6 为 278/82 ms）。课程项目必须冻结一个可复现版本时，按当前 ATCO2 证据选 WebRTC。
4. 该评测复用了已查看过的 49 段公开样本，边界参考来自 XML 转写时间，不是独立逐帧 VAD 标注；以上差异仅支撑本项目当前版本的工程选择，不是 VHHH 实测，也不是对总体性能的统计确认。

## 排除项

- SenseVoiceSmall `2024-07-17 int8`：保留作历史对照，不作为 A-4 当前英语 ATC 主识别器。
- Silero VAD v5.0：保留作现有实现和历史基线，不作为当前选定的分段器。
- Silero VAD 包 `6.2.3`：完成探索性补测，但没有优于 WebRTC 的稳定证据，不纳入当前确定版本。
- WhisperATC Large-v3 联合微调版：不进入本版本，原因见上面的数据重合和运行时元数据约束；其研究结果保留在专项报告中。

## 集成状态与验收

2026-10-21 已按该决议将 WebRTC VAD 与 XLS-R 接入 A-4 服务引擎协议和 CLI，并固定 GPU 依赖、模型权重及处理器校验、执行快照和回归测试。真实 XLS-R 在模拟 A-3/A-4 HTTP 边界通过保存、读回；全部49条 ATCO2 冻结集合逐段复现此前 WebRTC/XLS-R 输出，严格 WER 仍为40.81%。这不代表真实团队服务已联调：远端 P-Blue 最新 A-3/A-4 仍是501占位，A-5引擎登记也仍是CPU sherpa/SenseVoice配置。VHHH WAV是无语音测试信号且没有配套人工转写，需取得可用录音和人工参照后才能验收目标机场质量。

版本验收至少应确认：

1. 启动时检查 ASR checkpoint revision/权重哈希和 WebRTC wheel 版本，信息写入运行记录。
2. 相同音频、固定参数可重复得到相同分段与转写；禁用远程推理 API。
3. 无语音、末尾语音、长静音、短片段、模型初始化失败和 GPU 不可用场景按 A-4 需求返回明确状态。
4. 固定测试集上复算主指标、数字专项错误、分段边界代理指标、端到端耗时和峰值显存；目标机场数据须独立留出并遵守授权。
