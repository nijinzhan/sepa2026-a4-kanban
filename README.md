## 安装与验证

以下命令在本仓库根目录执行。已验证 Windows x64、Python 3.13.9；其他Python版本请按实现说明处理依赖。

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.lock.txt
.\.venv\Scripts\python.exe -m pip install -e . --no-deps
$env:A3_TEAM_REPO = 'D:\course_project\现代软件工程\SEPA2026_TeamBlue'
.\.venv\Scripts\python.exe -m pytest -q
.\.venv\Scripts\python.exe -m a4_speech --help
```

上述安装锁定清单同步自团队提交；PostgreSQL可选依赖需另安装 `psycopg[binary]>=3.2,<4`。真实模型需准备模型与样本，并设置 `A4_REAL_MODEL_CONFIG` 与 `A4_REAL_TEST_AUDIO`；数据库测试需有效的专用测试库。配置示例中的服务地址不是服务已部署的证明。

本仓库根目录不包含队友代码和团队Git对象。上面的 `A3_TEAM_REPO` 应改为本机有效团队仓库路径，本地A-3测试用例会从中加载原始存储与元数据源码。跨模块脚本应按[本地启动说明](docs/本地A3-A4-A5启动与联调.md)指定团队仓库路径，或直接在团队仓库的 `李洪/` 目录执行。V24和长音频工具默认使用原团队目录结构，个人副本不声称脱离团队仓库即可运行完整联调。

本仓库不上传本机凭据、`config.local.json`、模型权重、虚拟环境、缓存和原始运行输出。文档中的本机验证记录用于说明已有结果；模型和实际服务需在运行环境中配置。
