# 本地 A-3 / A-4 / A-5 联调实施

用户已确认本地入库、通知下载和统一启动三项工作，本轮直接执行。修改限定李洪个人目录，复用最新团队源码的固定快照。已有本地数据库仅用于功能联调，来源及初始化沿用已有记录；本轮不把它表述为主仓库空库部署验收。

## 运行设计

个人 A-3 适配服务调用刘亦含路径修复版 AudioStorage 和吴美娴 AudioMetadata，保留实际索引与 UUID；测量真实音频时长并登记同一 PostgreSQL。登记提交后通知刘睿 HTTP 自动服务，后者调用本方教师 SenseVoice 转写保存。于天名查询导出服务读取同一批文本，经个人 A-3 下载端点取得对应音频。四个服务只监听 127.0.0.1，使用本地服务密钥。

输入采用真实历史 MP3 的短切片，记录原文件哈希、切片偏移和实际时长；UTC 未独立核实，明确标为测试时间锚点。A-3 演示文字文件不进入此流程。先验证短切片，避免触发现有 A-5 长单段导出溢出；不修改其公共函数。IAM 权限与在线采集不属于本次闭环。

## 验收

同一 A-3 audio_id 对应 A-5 recording.id、自动任务 audioId 和查询 recordingId；文件哈希一致；有真实转写文本及确认保存；导出的文本和切片来自同一录音。重复入库及通知不增加录音、识别任务或文本。没有修改他人源码、共享 DDL，或把模拟音频、历史重排文本用于本轮成功结论。
