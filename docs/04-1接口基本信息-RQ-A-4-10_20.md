## 接口一 分段转写

### 1. 接口基本信息

* **接口名称**：分段转写
* **接口功能**：按已登记录音UUID取得音频，校验元数据与时间，进行VAD和ASR，返回文本、相对/绝对时间及处理状态；本入口不保存初始文本。
* **请求方式**：`POST`
* **请求路径**：`/api/v1/a4/speech/transcribe`
* **协议类型**：本机HTTP；正式部署按登记的HTTP(S)地址调用。
* **接口版本**：`v1`，个人服务`0.2.0`
* **接口负责人**：李洪

转写会登记片段、识别任务和处理元数据；“不保存初始文本”不等于完全没有上游写入。`maxSegments`是服务部署配置，正整数，默认500，不是调用方可以在本请求中临时传入的字段。VAD后超限先拒绝，再登记/建任务/推理；当前没有自动分批协议。

### 2. 请求参数 (Request)

#### 2.1 Header 参数（请求头）

| 参数名 | 类型 | 必填 | 默认值 | 说明 |
| :--- | :--- | :--- | :--- | :--- |
| Content-Type | string | 是 | application/json | JSON请求体 |
| X-Api-Key | string | 是 | 无 | 入站服务密钥，由`A4_SERVICE_API_KEY`配置；不是用户Bearer |
| Idempotency-Key | string | 是 | 无 | 1—64个可打印ASCII字符，不能全空白；关联本次录音处理，不用新键绕过已有结果或未知状态 |
| X-Request-Id | string | 否 | 服务生成 | 1—128位，字符集`A-Za-z0-9_.:-`；用于当前调用追踪，不能代替幂等键 |

#### 2.2 Body 参数（请求体 - JSON）

| 参数名 | 类型 | 必填 | 默认值 | 说明 |
| :--- | :--- | :--- | :--- | :--- |
| recordingId | string(UUID) | 是 | 无 | A-3已登记录音的标识，不接收本机文件路径或任意音频URL |
| businessTaskId | string(UUID)或null | 否 | null | 上层业务任务逻辑标识；只转写可省略，独立保存前必须补充；不是asr.job.id |

**请求体示例 (Request Body Example)**：

```json
{
  "recordingId": "00000000-0000-4000-8000-000000000001",
  "businessTaskId": "00000000-0000-4000-8000-000000000002"
}
```

### 4. 错误码说明 (Error Codes)

| HTTP状态 | 错误码 (code) | 错误描述及产生原因、处理建议 |
| :--- | :--- | :--- |
| 400 | VALIDATION_ERROR / INVALID_REQUEST_ID | UUID、请求字段、幂等头或追踪头无效；修正后调用，框架参数校验在本服务映射400 |
| 401 | UNAUTHORIZED | 入站服务密钥缺失或无效 |
| 404 | 上游原始code | 已登记录音不存在等明确上游404；按录音UUID核对 |
| 409 | IDEMPOTENCY_CONFLICT / REQUEST_ALREADY_SUBMITTED / REQUEST_OUTCOME_UNKNOWN | 幂等冲突、重复处理或既有结果未知；先按已知任务/回执核对 |
| 409 | RESULT_EXISTS / SEGMENT_BUSY / SEGMENT_CONFLICT | 已有文本、片段占用或区间冲突；不通过新幂等键覆盖 |
| 422 | JOB_SEGMENT_LIMIT | 超过本次部署配置上限，附segmentCount/maxSegments；不截断或自动切批 |
| 422 | INVALID_RECORDING / INVALID_TIME / INVALID_SEGMENT / TIME_MISMATCH | 录音、时间或边界语义不符合要求 |
| 429 | SERVICE_BUSY | 单进程模型正在处理，核心受理前拒绝；Retry-After为1 |
| 502 | TRANSPORT_ERROR / INVALID_RESPONSE，或上游code | 上游连接、超时或非预期响应；先核对可能发生的写入，不盲目重发 |
| 503 | MODEL_UNAVAILABLE / MODEL_MISMATCH / ENGINE_UNAVAILABLE / ENGINE_CONFIG_MISMATCH | 模型或登记与配置不可用/不一致，核对部署及快照 |
| 503 | POSTGRES_UNAVAILABLE / POSTGRES_DRIVER_UNAVAILABLE | 显式PostgreSQL模式存储或驱动不可用 |
| 500 | INTERNAL_ERROR | 未预期内部异常，按requestId定位日志 |

公共提供方的400/401/403/404/409/422可保留HTTP状态及原始code；其他上游HTTP异常通常映射502。上游403不等于本方人工编辑权限校验已触发。业务识别失败也可能通过200和结构化状态返回。

## 接口二 初始保存

### 1. 接口基本信息

* **接口名称**：初始转写结果保存
* **接口功能**：接收此前转写的完整结果，核对任务、片段、模型与摘要，保存有效文本并读回确认。
* **请求方式**：`POST`
* **请求路径**：`/api/v1/a4/speech/results/save`
* **协议类型**：本机HTTP；正式部署按登记的HTTP(S)地址调用。
* **接口版本**：`v1`，个人服务`0.2.0`
* **接口负责人**：李洪

只保存已有机器初稿，不触发模型、不取得转写模型锁，不要求转写幂等键。本接口不是人工修订入口；部分成功只保存有效子集，处理结果仍为partial。已有关联不得在本次调用改绑。

### 2. 请求参数 (Request)

#### 2.1 Header 参数（请求头）

| 参数名 | 类型 | 必填 | 默认值 | 说明 |
| :--- | :--- | :--- | :--- | :--- |
| Content-Type | string | 是 | application/json | JSON请求体 |
| X-Api-Key | string | 是 | 无 | 入站服务密钥 |
| X-Request-Id | string | 否 | 服务生成 | 当前保存请求追踪标识，规则同转写接口 |

#### 2.2 Body 参数（请求体 - JSON）

| 参数名 | 类型 | 必填 | 默认值 | 说明 |
| :--- | :--- | :--- | :--- | :--- |
| result | object | 是 | 无 | 上一个转写接口返回的完整结果；不能仅传textRaw数组 |
| result.businessTaskId | string(UUID) | 是 | 无 | 若转写时缺省，保存前可补充尚未绑定的业务任务UUID；已绑定不能改绑 |
| result.schemaVersion / recordingId / jobId | int / UUID / UUID | 是 | 无 | 来源格式、录音和执行任务；需与服务器任务一致 |
| result.status / processedSegments / failedSegments | string / int / int | 是 | 无 | 原处理结果和计数，不能为方便保存而改成succeeded |
| result.transcripts | array | 是 | 无 | 原有效片段、原文、语言及时间，完整保留 |
| result.failedSegmentsDetails / unprocessedSegmentIds / targetSegmentIds | array | 按原响应完整保留 | 无 | 原失败与目标清单，不删改以绕过核验 |
| result.executionSnapshot及其它来源字段 | object等 | 按原响应完整保留 | 无 | 模型、音频转换、追踪及处理元数据用于核验，不自行制造 |

| 401 | UNAUTHORIZED / REVISION_AUTH_REQUIRED / REVISION_AUTH_DENIED | 入站密钥、用户Bearer缺失/无效或身份拒绝；以具体返回区分 |
| 403 | REVISION_AUTH_DENIED，或上游code | 用户停用或没有实际编辑权限；不得换服务密钥冒充用户 |
| 404 | 上游原始code | 文本不存在 |
| 409 | REVISION_CONFLICT | 期望版本过旧，重新读取后决定是否修改；不覆盖他人结果 |
| 502 | REVISION_UNCONFIRMED | 缺少可信未写入/回滚证据的提交异常或写入后读回未确认；saveStatus=unconfirmed、writeOutcome=unknown，先GET核对，不盲目重发 |
| 503 | REVISION_AUTH_UNAVAILABLE | 本地身份服务未配置/不可用/响应无效；写入前退出，saveStatus=failed、writeOutcome=not_written |
| 503 | REVISION_HISTORY_INVALID | 本地历史校验失败且事务上下文已完成回滚；saveStatus=failed、writeOutcome=rolled_back |
| 422 | INVALID_REVISION，或关联核验码 | 业务修订参数/来源核验不通过 |
| 502 | HISTORY_UNAVAILABLE / INVALID_RESPONSE / TRANSPORT_ERROR等 | 读取来源/历史或上游异常；具体code取决于异常发生在写入前、写入时还是读回时 |
| 503 | POSTGRES_UNAVAILABLE / POSTGRES_DRIVER_UNAVAILABLE | 显式PostgreSQL存储不可用 |
| 503 | MODEL_UNAVAILABLE | 工作服务对象未就绪时的现有码；不是修订需要模型推理 |
| 500 | INTERNAL_ERROR | 未预期内部异常 |

同版本且无实际变化应成功返回原版本；`REVISION_UNCHANGED`为兼容异常分支可能出现的409，不把它当成所有无变化请求的必然结果。文本和状态实际改变时，版本、当前值及真实历史需在同一事务或等效原子操作中一致，原文不变。

**2026-11-10修复后的错误分层**：仅本地适配器可以携带`not_written/rolled_back`证据；历史校验异常必须在事务上下文完成异常退出后才标记已回滚。修订服务保留对应503、原始code、中文原因及保存状态。回滚无法确认、远程5xx/无效响应和提交后的读回校验失败仍为`502 / REVISION_UNCONFIRMED`。HTTP错误正文中的writeOutcome及同名错误码不作为本地证据；未确认必须先读回，不自动重发。修复前的两项模拟结果保留在测试报告T08；本轮代码与组件验证见[修复记录](../deliverables/测试/2026-11-10-修订错误语义修复与白盒分析-RQ-A-4-20.md)，真实数据库复测尚未执行。

## 通用错误响应示例与调用注意事项

下例仅展示通用Problem JSON结构，requestId及路径为格式示例。其它错误按实际code和HTTP状态处理。

```json
{
  "type": "about:blank",
  "title": "文本已被修改，请重新读取当前版本后再提交，勿覆盖他人修订。",
  "status": 409,
  "detail": "文本已被修改，请重新读取当前版本后再提交，勿覆盖他人修订。",
  "instance": "/api/v1/a4/transcripts/00000000-0000-4000-8000-000000000010",
  "code": "REVISION_CONFLICT",
  "message": "文本已被修改，请重新读取当前版本后再提交，勿覆盖他人修订。",
  "requestId": "doc-error-example",
  "traceId": "doc-error-example"
}
```

* 转写新结果后需要保存时，调用接口二；拿到transcripts[].id后再GET/PATCH。上层业务任务UUID与ASR执行任务UUID用途不同。
* 服务密钥通过环境变量配置，不写入正文、源码或日志；上游服务密钥`A4_API_KEY`与入站`A4_SERVICE_API_KEY`按各自配置使用。修订的真实用户Bearer另行取得。
* 转写专用门禁不限制无关记录的保存、读取和修订；共享CPU、内存、线程、网络与数据服务仍可能导致延迟或不可用，不承诺任意负载固定时限。
* HTTP模式的公共调用与显式PostgreSQL模式分别配置。当前历史数据库实验不等于团队main已独立部署；正式联调使用团队主仓库确认的服务、结构及真实身份。
