| 输入 | 总时长 | VAD输出，单位毫秒 | ASR执行及检查 |

三次命令均退出0；片段均满足 `0 <= startMs < endMs <= ceil(durationMs)`，按时间排序且互不重叠。第二段时间位于拼接音频的第二份样例范围内，未重置为从0开始。

单段样例实际输出为：

> The tribal chieftain called for the boy and presented him with 50 pieces of gold.

拼接样例第一段输出相同，第二段以 `Tribal chieftain` 开头，少了开头的 `The`。这一差异已保留在原始输出中；当前结果不能作为无漏词或达到空管领域识别准确率的证明。后续需使用实际空管语音及人工参照文本评估分段边界和转写质量，再决定是否调整VAD参数或模型。当前没有人工标注语音起止的基准，不能据此声称时标精度已验收。

本机证据位于 `outputs/real-model/`：

- `english.stdout.json`、`silence.stdout.json`、`two-utterances.stdout.json`：CLI原始标准输出，含模型快照、片段时间和文本。

- `summary.json`：执行时间、输入哈希、退出码、实际输出及检查结果。记录的进程耗时包含启动、模型加载、文件哈希等，不作为纯推理速度指标。

## 3. 复现

在本仓库根目录执行（对应团队仓库中的个人目录）。原验证环境已具备以下模型文件；新环境需从第1节官方链接下载VAD和模型包，将前者命名为 `models/silero_vad_v5.onnx`，后者解压到 `models/`，并按 `config.example.json` 创建本地配置。

```powershell
# 先在终端进入当前仓库根目录
.\.venv\Scripts\python.exe -m a4_speech --config config.local.json check-model --audio '.\models\sherpa-onnx-sense-voice-zh-en-ja-ko-yue-int8-2024-07-17\test_wavs\en.wav'

$env:A4_REAL_MODEL_CONFIG = (Resolve-Path '.\config.local.json').Path
$env:A4_REAL_TEST_AUDIO = (Resolve-Path '.\models\sherpa-onnx-sense-voice-zh-en-ja-ko-yue-int8-2024-07-17\test_wavs\en.wav').Path
.\.venv\Scripts\python.exe -m pytest -q
```

本次完整测试结果为 **156 passed in 5.64s**，没有跳过项；其中真实模型用例检查Silero静音判定、官方语音分段和SenseVoice非空转写。Ruff静态检查、15个文件的格式检查及 `pip check` 均通过。
