## 3. 结果怎样解释

### 3.1 ASR：承认已测到的质量差异

固定集合为49条公开 ATCO2 英语录音，共327.616秒，来自7个机场，严格参考共892词；不含 VHHH。严格 WER 越低越好，它是词错误率，不能直接称为“识别准确率”。

| 分段输入 | 通用 SenseVoice int8 严格WER | ATC微调 XLS-R FP32 严格WER |
|---|---:|---:|
| XML人工区间，诊断控制组 | 79.15% | 39.80% |
| Silero v5.0 | 82.29% | 43.05% |
| WebRTC | 82.29% | 40.81% |

在这组既定配置与样本上，XLS-R 的 WER 明显更低；不能为了恢复原方案而把它写成“效果相同”或“没有提升”。对照包含通用模型与领域微调模型、int8与FP32的差异，尚未单独分离这些因素，因此不能把全部提升归因于网络架构。

SenseVoice 使用 CPU，XLS-R 使用 GPU；既有运行耗时不能直接用于宣称某模型在相同硬件下更快。原默认组合82.29%的严格WER也提示英语ATC自动转写质量风险仍待处理；恢复配置不等于该质量问题已解决。

### 3.2 VAD：各项指标有取舍

WebRTC 对 XML 参考区间的语音时长覆盖率为98.10%，Silero v5为89.01%；对应时长精确率为93.32%和97.36%。覆盖率更高表示漏掉的参考语音更少，精确率更高表示预测区间中夹带的非参考语音时间更少，两者并非同一指标。

固定 XLS-R 后，WebRTC、Silero v5、Silero v6 的严格WER分别为40.81%、43.05%、41.93%；既有配对分析未证明VAD之间存在稳定的WER优势。这也不构成三者等效的证明。XML转写区间仅为边界代理，不能当作已复核的逐帧VAD真值。现有结果支持记录取舍与风险，尚不支持“某VAD全面领先”的表述。

### 3.3 WhisperATC：保留数据划分和提示词条件

作者联合微调版在113条公开验证集上，严格WER从无提示词的47.63%降至加元数据提示词后的16.96%。该验证集用于作者模型选择，提示词还使用机场、航路点、候选呼号等额外信息，因此不是本项目独立测试成绩。原49条中38条与该模型的公开训练成员重合，其低WER只能作诊断，不能写成泛化或VHHH验收结果。

### 3.4 集成：与真实服务验收分开记录

XLS-R/WebRTC 曾通过真实本地模型与模拟HTTP接口完成49条录音、54个分段的保存和读取，输出与原实验逐条一致。这验证了实验引擎与现有业务协议的适配。真实A-3/A-4/A-5服务的部署、登记、数据持久化及协作联调仍须另验。

### 周报

本周完成公开ATCO2英语空管录音的识别基线与模型、VAD比较实验，整理固定样本、参考文本筛选、参数与版本、WER、边界代理指标和问题清单，并验证实验引擎经模拟接口保存和读取结果的流程。实验发现ATC微调XLS-R在当前样本上的词错误率低于现有通用SenseVoice，但涉及模型领域适配、精度和运行硬件差异，且缺少目标机场独立验收数据。结合课程既定需求与交付范围，主实现恢复为sherpa-onnx + SenseVoice，保留比较成果作为技术评估和质量风险证据；后续重点完成课程权重确认、真实服务联调和需求验证。

### 测试分析报告

本轮测试用于诊断既定识别方案在公开英语ATC录音上的表现，并评估可替换引擎的适配可行性。在固定49条非VHHH样本上，原Silero v5 + 通用SenseVoice int8组合的严格WER为82.29%，WebRTC + ATC微调XLS-R组合为40.81%；固定同一分段条件的六组对照同样显示XLS-R质量优势。该结果不能替代课程指定SenseVoice ATC微调权重的测试，也不能直接外推VHHH。当前默认方案按课程需求恢复，识别质量风险保留在问题清单中，尚不据此判定准确率验收通过。

### 答辩时说明为什么比较后仍恢复

我们通过比较实验识别了原方案的英语ATC质量风险，也验证了引擎接口具有替换能力。当前交付沿用课程既定技术路线，并优先完成职责范围内的分段、时间对应、结果管理、异常处理与真实服务联调。替代模型在本批数据上更好，但还没有完成课程指定权重对照、目标机场独立验证和部署约束核对，因此将它作为有证据的改进方向保留。本次恢复属于需求与配置管理决策，识别质量问题仍需如实报告。
